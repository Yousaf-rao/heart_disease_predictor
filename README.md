# ❤️ Heart Disease Predictor - CardioAI

Advanced Multi-Model Heart Disease Prediction Dashboard built with Streamlit.

## Features
- **Single Prediction**: Enter patient data and get predictions from 4 ML models
- **Bulk Prediction**: Upload CSV file for batch predictions
- **Model Metrics**: Compare Accuracy & F1-Score of all models
- **Data Analysis**: Full EDA visualizations on the dataset

## Models Used
- Logistic Regression
- Random Forest
- SVM (Support Vector Machine)
- Decision Tree

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
